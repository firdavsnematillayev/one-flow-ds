# One Flow DS — плагин дизайн-системы

Плагин для Claude: помогает дизайнерам, продакт-менеджерам и разработчикам работать по дизайн-системе One Flow (DS v2).
Источник правды — опубликованная библиотека **design systems v2** в Figma: плагин читает её живьём и несёт готовый кит для кода, снятый с неё же и сверенный.

## Что внутри

| Часть | Что делает | Как вызвать |
|---|---|---|
| **one-flow-ds** | Знания о системе: главные правила, токены, каталог компонентов, принятые решения, тексты, где лежат правила в Figma, скрипт проверки макета. Кит для кода (см. ниже). Включается сам при задачах по дизайну и вёрстке. | просто писать о задаче: «какой компонент взять для…», «сверстай страницу по DS» |
| **build-screen** | Собирает экран или черновик в Figma только из компонентов библиотеки, проверяет тёмную тему и правила. Продакт-менеджеры собирают на странице «Черновики». | «Собери экран заявки на отпуск в <ссылка на файл>» |
| **review-design** | Проверяет фрейм: цвета не из токенов, текст без стилей, чужие шрифты, радиусы, отступы, отвязанные компоненты, логику и тексты. Даёт список правок. | «Проверь макет <ссылка на фрейм>» |
| **dev-handoff** | Токены и компоненты для кода (с тёмной темой, контрастом и брендом клиента), спецификации, состояния и поведение. Начинает с готового кита, Figma — только если чего-то в ките нет. | «Выгрузи токены в CSS», «Спецификация для filter-bar» |
| **ds-sync** | Только для владельца DS: сверяет Figma с плагином по отпечатку (токены, иконки, каждый компонент и доска правил), переносит изменения, проверяет и выпускает новую версию. | «Обнови плагин», «Я поменял дизайн-систему» |
| **Figma** | Подключение к Figma (коннектор). | ставится вместе с плагином |

## Кит для кода (`skills/one-flow-ds/assets/`)

- `tokens.css` + `typography.css` — все токены DS v2: цвета в 4 режимах (`data-theme="light|dark"`, `data-contrast="more"`), бренд клиента (`data-brand="client-example"`), отступы, радиусы, тени, движение, 50 текстовых стилей. Сверены с Figma по хэшу.
- `components.css` — компоненты всех страниц DS v2 (атомы, молекулы, организмы, шаблоны) и каркас страницы `.of-shell` классами `.of-*`; разметка — в комментариях к каждому блоку и в `references/components/*.md`. Чего в CSS нет — в разделе «Чего пока нет».
- `icons.svg` — спрайт иконок Icons OneFlow (`<svg class="of-icon"><use href="#i-plus-line-20"/></svg>`), 200 иконок, сверены с библиотекой. Вставляется целиком первым в `<body>`.
- `logo/` — значок приложения (`logo-app-icon.svg`, по умолчанию в шапке) и знак One Flow (`logo-symbol.svg`) со страницы logo DS v2.
- `components-preview.html` — образцы всех компонентов со встроенной сверкой с Figma (852 образца × 2 темы). Файл больше 500 КБ: открывать через локальный сервер, например `python3 -m http.server --directory skills/one-flow-ds/assets` → `http://localhost:8000/components-preview.html`. Вверху — «Совпадает с Figma: …» и переключатель темы.
- `preview.html` — доска токенов со сверкой.

Экран в коде строится только на этих файлах: ни своего HEX, ни размера шрифта или отступа вне токенов. Как подключить и собрать — `skills/one-flow-ds/references/code-screen.md`.

## Установка

Плагин живёт в приватном репозитории **github.com/firdavsnematillayev/one-flow-ds** и обновляется у всех сам. Нужен аккаунт GitHub с доступом к репозиторию: владелец приглашает коллег (Settings → Collaborators).

**Claude Code** (разработчики):
1. Один раз войти в GitHub на своём компьютере:
   ```bash
   brew install gh && gh auth login && gh auth setup-git
   ```
2. Добавить маркетплейс и установить плагин:
   ```bash
   claude plugin marketplace add firdavsnematillayev/one-flow-ds && claude plugin install one-flow-ds@one-flow
   ```
   В Claude Code 2.1.275 и новее то же самое делает одна команда: `/plugin install one-flow-ds --marketplace firdavsnematillayev/one-flow-ds`.
3. Включить автообновление: `/plugin` → Marketplaces → one-flow → Enable auto-update. Новая версия придёт сама в течение 10 минут после начала сессии; применить — `/reload-plugins` или перезапуск.

**Приложение Claude и claude.ai** (дизайнеры, продакт-менеджеры): Customize → Plugins → Add → Add marketplace → `firdavsnematillayev/one-flow-ds`. Когда попросят — подключить GitHub. Затем включить **Sync automatically**.

**Без доступа к репозиторию** (разово, без обновлений):
- архив `one-flow-ds.zip` — `claude --plugin-dir one-flow-ds.zip`; файл `.plugin` этот флаг пропускает молча;
- или `one-flow-ds.plugin` — загрузить в разделе плагинов.

**Проверить, что плагин загрузился:** спросить «какие навыки one-flow-ds тебе доступны?». Должно быть пять: one-flow-ds, build-screen, review-design, dev-handoff, ds-sync.

После установки:
1. Войти в Figma, когда Claude попросит подключить коннектор.
2. Получить доступ к файлу библиотеки «design systems v2»: на просмотр — для скриншотов досок правил и описаний компонентов; читать текст досок скриптом и обновлять кит — только с доступом на редактирование (владелец DS). Без доступа правила каждой доски пересказаны в `references/components/*.md`.
3. В своих рабочих файлах Figma подключить библиотеки **design systems v2** и **Icons OneFlow** (Assets → Libraries).

Кит для кода работает и без доступа к Figma.

## Что проверить при тесте

- Спросить о правиле («какой радиус у карточки?», «как показать статус?») — ответ должен ссылаться на правила DS и решения владельца.
- Попросить сверстать страницу (например, список заявок с фильтрами и таблицей) — результат только на классах `.of-*` и токенах, в каркасе `.of-shell`, в светлой и тёмной теме; флажки отмечаются, окно открывается и закрывается.
- Открыть `components-preview.html` через локальный сервер — вверху должно быть «Совпадает с Figma».
- С доступом к Figma: собрать черновик экрана (`build-screen`) и проверить фрейм (`review-design`).

## Чего пока нет

- Мобильных компонентов (iOS / Android) — будут после веба.
- Автоматической проверки контраста и тёмной темы в скрипте проверки макета — их смотрят по скриншоту.
- В CSS: button-group, select-menu в состояниях empty / loading, строка-скелетон таблицы, меню размера страницы таблицы (в Figma они есть — собирать из `.of-select-menu`, `.of-skeleton`).
- Ответов владельца DS на открытые вопросы — список в `skills/one-flow-ds/references/decisions.md` (там же — как это сделано в коде до ответа).

## Обновление

- **Правила и описания компонентов** плагин читает из Figma живьём. Кит для кода — снимок: дата и отпечаток лежат в `skills/one-flow-ds/references/figma-fingerprint.json`.
- **Владелец DS** после правок в Figma пишет в Claude Code «обнови плагин» (навык `ds-sync`). Claude:
  - сверяет отпечаток — показывает, какие токены, иконки, компоненты и доски правил изменились;
  - переносит изменения и проверяет доску сверки;
  - поднимает версию и собирает архив.
- **Как новая версия доходит до команды**: `ds-sync` поднимает версию и отправляет изменения в репозиторий (`git push`). У коллег с автообновлением она появляется сама: в Claude Code — после начала сессии, в приложении — при включённом Sync automatically.
- **Номер версии** — в `.claude-plugin/plugin.json`. Без новой версии участники обновление не получат.
