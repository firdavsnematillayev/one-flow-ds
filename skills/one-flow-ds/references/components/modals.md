## Правила (доска «modals rules (DS2)» `1211:630`)
- **Что выбрать**:
  - s 480 — короткая форма, 1–3 поля;
  - m 640 — обычная форма, просмотр;
  - l 960 — сложная задача: таблица выбора, несколько шагов;
  - dialog 400 — подтверждение, tone=danger — для необратимого;
  - если рядом должен оставаться список — шторка (drawer), а не окно.
- **Шапка и футер**: заголовок говорит, что делаем («Новая заявка»). Крестик справа всегда. «Назад» — только в шагах. Главная кнопка справа, «Отмена» слева от неё.
- **Поведение**:
  - фон затемняется, страница под окном не прокручивается;
  - закрыть можно крестиком, Esc или кликом по фону; если есть несохранённые данные — сначала спросить;
  - окно появляется за 320 ms (`duration/base`, `easing/flow`), без отскока. В коде — `data-enter`.
- **dialog**: заголовок — вопрос, текст — последствие («Заявка удалится без возможности восстановить»). Кнопка называет действие: «Удалить», а не «Да». Если действие можно отменить — сделать сразу и показать undo-toast, а не спрашивать.
- **Нельзя**: окно поверх окна; окно для сообщения об успехе — для этого toast.

## Разметка
Полная — в комментарии к блоку `modals` в `components.css`. Открыть / закрыть — атрибут `hidden` на `.of-modal-backdrop`, появление — `data-enter` у `.of-modal`. Пока окно открыто, приложение запрещает прокрутку страницы (`overflow: hidden` на `<html>`), держит фокус внутри и закрывает окно по Esc и клику по фону.

## Расхождения в Figma
1. **Форма кнопок футера.** На доске правил написано «кнопки l 44, пилюли», и общее правило кнопок — «round в окнах», а в компоненте modal, dialog и во всех примерах страницы — shape=default (скругление `radius/m`); у шторки — round. В коде — как в компоненте (вопрос 18).
2. **Промежуток между полями формы** в окне не задан: в примерах вместо содержимого заглушка `modal-slot`. В коде — `space/16` (вопрос 24).
