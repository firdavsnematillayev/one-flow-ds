# Принятые решения DS v2

Решения владельца DS. Если в Figma на доске правил написано иначе — верна доска (она новее). Не предлагать заново то, что здесь помечено как отклонённое.

## Формы и поля
- Поле = заголовок внутри поля, при вводе он поднимается. **Отклонено:** подпись над полем и поле с одним плейсхолдером. При вводе двигается только заголовок; префикс, код страны, чипы, «+3» — на строке значения.
- Select — это input с шевроном + `select-menu`. Combobox — input в фокусе + меню. Пароль и время — input с иконкой глаза / часов. Отдельных компонентов для них нет.
- multi-select показывает текст выбранного и «+3», без чипов внутри поля.
- Один вид полей на форму: либо серые (`input`), либо обведённые (`input-outline`).
- Ошибка — под полем, текст «что не так + как исправить». Проверка при уходе из поля и при отправке.

## Кнопки
- Одна primary на блок. Размеры: xs 24 (строки 44), s 32 (строки 56, карточки), m 36 (основной веб), l 44 (окна, мобильный), xl 52.
- Пилюли (round) — окна, шторки, тосты, карточки; прямоугольные — шапка страницы, таблицы, панели.
- «Ещё действия» — горизонтальное троеточие, всегда.

## Таблица и фильтры
- Таблица в белой карточке на сером фоне. Строки 56 (m) / 44 (s).
- Первая колонка — номер; при наведении становится флажком (если роль может выбирать). Номер — позиция в виде, не ID; при группировке идёт сквозной через все группы.
- Действия строки — одна кнопка «Ещё» в последней колонке; редактирование внутри её меню.
- Футер: «1–10 из 48» → «Строк на странице 10/20/50/100» → пагинация справа.
- Группировка: страницы считают группы (10 на страницу), в группе первые 10 строк + «Показать ещё N», у группы флажок.
- Фильтры — одна схема везде: поиск + кнопка «Фильтры · N». Активные фильтры — строка чипов под панелью, «+N» при переполнении, «Сбросить» последним (с undo-toast 5 с). Окно фильтров: слева «Готовые» наборы и поля, справа значения; применяется сразу, без «Применить». Закрепление как в Telegram — поле поднимается наверх списка внутри окна. **Отклонено:** отдельные выпадающие фильтры рядом с кнопкой «Фильтры», закреплённое поле в панели.
- Мобильные таблицы и фильтры — позже.

## Окна и поверхности
- Большие поверхности (окно, шторка) — `surface/default`; маленькие всплывающие (меню, поповер, тост, календарь) — `surface/elevated`.
- modal s 480 / m 640 / l 960, dialog 400 (tone danger для необратимого). Окно поверх окна нельзя. Успех — toast, не окно.
- Шторка (drawer) — когда список рядом должен оставаться виден; s 400, m 560.

## Навигация и каркас
- Верхняя панель справа: поддержка → уведомления → приложения → профиль. На колокольчике красный счётчик с числом.
- Боковое меню: 284 от 1440 px, 72 ниже. Активный пункт — синяя полоса у края + светло-синий фон + полужирный + иконка solid. «Скрыть» — пункт внизу меню. **Отклонено:** круглая кнопка сворачивания на краю.
- Сотрудник: Главная, Структура, Посещаемость, Формы, «Моё подразделение» (только руководитель). Администратор: Мониторинг, Главная, Аналитика, Кадровое дело, Плановый, Директория, Конфигурация. Переключатель ролей — в нижней строке меню.
- Контент max 1104 по центру; при широком экране по бокам поля, ничего не растягивается.
- По клику на вкладки страница не прокручивается.

## Главная и виджеты
- Сетка: баннер 1104; приложения 624 + две плитки 144 + посещаемость 304; лента 784 + колонка 304.
- Виджеты в одном стиле: белые, радиус 24, заголовок с шевроном, главное число крупно + статус словом.
- Настроение: вопрос серыми лицами, наведённое цветное, после ответа — итог команды; итог только от 5 ответов.
- Приложения: до 7 + «+N Все приложения», «Добавить» последним; порядок общий с меню приложений. Компании — только переставить; свои закладки — добавить, изменить, удалить.

## Лента, посты, комментарии
- Пост в ленте 784; фото — коллаж (пятое «+N»), карусель только в открытом посте; видео — обложка, звук выключен.
- Опрос: результаты после голоса, голос изменить нельзя.
- Реакции: Like, Celebrate, Love, Fire, Useful — без подписей. Кнопка реакции — круглая иконка, рядом чип «отметки + число». Просмотры видят все, список — автор и администратор.
- Меню поста: читатель — «Скопировать ссылку»; автор — + «Изменить», «Удалить». Закрепление — иконка булавки рядом с меню.
- Комментарии: два уровня. Ответ на ответ остаётся в ветке и получает метку адресата (стрелка + имя), это ссылка. Видны первые 2 ответа, дальше «Показать ещё N» (по 10), «Скрыть ответы». Поле ответа — в конце ветки, «Ответ для: Имя» + крестик, одно на пост. От старых к новым. Удалённый с ответами — «Комментарий удалён». Нет комментариев — `comments-empty`.

## Графики
- Ряды синими по порядку (`chart/1…4`), до четырёх, остальное «Другое». Spark никогда не ряд — только цель, порог, выброс (одна точка или тонкая линия с подписью).
- Ниже цели — более светлый синий, не красный. Статусные цвета в графиках не используются.
- Раскладка «большой + два половинной высоты»: пары карточек одной высоты, растёт график у более короткой.
- У графика всегда период и источник; есть вид «таблица».

## Логотип
- Только мастер-файлы, не перерисовывать и не набирать шрифтом. Словесный знак отдельно не используется.
- Фавикон: 32 — полный цвет, 24 — плоский, 16 — сплошной Blue 600 (как в брендбуке).
- Модуль: «логотип | Название» Onest Medium. Партнёр — через «×».

## Движение
- Без отскока и пружины. Длительности и кривые только из токенов / стилей `Motion/*`.
- Заставка «Слои» 4 с — только запуск приложения, вход на сайт (раз за сессию), видео, сцена. При «Уменьшить движение» — сразу финальный кадр.

## Тёмная тема
- Это не отдельные компоненты, а режим Dark коллекции `colors`. Каждый экран проверять в обоих режимах.
