# Собрать экран из DS v2

Сначала загрузить навык `one-flow-ds` и прочитать `references/patterns.md` и `references/figma-howto.md` из него.

## 1. Понять задачу

- Что за экран, для какой роли (сотрудник, руководитель, администратор), какие данные и действия.
- В каком Figma-файле и на какой странице собирать. Нет ссылки — спросить.
- Кто просит: дизайнер или продакт-менеджер. **Продакт-менеджер** — собирать только на странице «Черновики» (создать, если её нет) и подписать фрейм «Черновик · <тема> · <дата>»; в чистовые страницы не класть.
- Если задача неясна — задать до трёх коротких вопросов. Если всё понятно — не спрашивать.

## 2. План до сборки

Коротко показать пользователю: каркас (верхняя панель, боковое меню, контент 1104), какие блоки и какими компонентами DS. Если нужного компонента нет — сказать прямо и предложить собрать из существующих частей; новые компоненты в библиотеку не добавлять.

## 3. Сборка

- `get_libraries` → `search_design_system` по библиотеке design systems v2 → импорт компонентов по ключу.
- Каркас страницы — `nav-bar` + `side-bar` + фон `surface/page` + контейнер 1104 по центру (см. `foundations.md`).
- Собирать по секциям: одна секция — один вызов `use_figma`, после — `get_screenshot`.
- Только экземпляры компонентов, только роли `colors`, стили `web/*` и `mono/*`, отступы `space/*`, радиусы `radius/*`. Ни одного HEX.
- Данные — выдуманные, правдоподобные, на языке продукта. Неизвестное — `[X]`.
- Состояния, если экран их предполагает: загрузка (скелетон), пусто (`empty-state`), ошибка. Делать отдельными фреймами рядом.

## 4. Проверка

1. Запустить `scripts/lint.js` навыка `one-flow-ds` на собранном фрейме, исправить все `error` и разумные `warning`.
2. Сделать копию фрейма рядом, выставить режим Dark коллекции `colors`, снять скриншот — проверить, что ничего не пропало.
3. Сверить с правилами страниц использованных компонентов (`rules-index.md`).

## 5. Отчёт

Коротко: что собрано (ссылка на фрейм), из каких компонентов, какие решения приняты самостоятельно, чего не хватило в DS, итог проверки (сколько замечаний было и осталось). Скриншот приложить.
